# Achiles Calilung: Portfolio Website

My personal portfolio, live at **https://achilesnikkolo.github.io**.

Front-end developer and Shopify specialist with 5 years of experience
supporting Shopify merchants.

## Built with
- HTML, CSS, and plain JavaScript (no frameworks or build tools)
- Hosted on GitHub Pages

## Features
- Bento grid layout with light and dark mode
- Animated theme toggle using the View Transitions API
- Scroll-driven animations and spotlight hover effects
- Profile photo that reveals a Memoji avatar on hover
- A Filipino coffee quiz built from scratch with JavaScript
- Accessible mobile menu using the native popover attribute

## Quality
- Lighthouse: Performance 97, Accessibility 100, SEO 100
- Keyboard navigation, visible focus styles, and reduced motion support

## History
Originally built in 2021, then fully redesigned in 2026.
